# 更新与兼容

以服务器 `oprun://integration/manifest` 资源、`tools/list` 和实际授权为准。清单列出业务契约、Skill 文件摘要、SDK 和不可变 UI 版本。文件摘要只能确认完整性，不能替代对发布者的信任。

1. 已安装 ZIP / 插件不一定随服务器自动更新。比较清单版本后，使用该宿主的原生更新或重新加载流程；只在不兼容时提示用户更新，不反复要求重新授权。
2. `resources/read` 读取 Skill 不等于宿主激活 Skill。仅双方明确支持 Skills 扩展时才使用远程加载；其他客户端继续使用标准 Skill 包。
3. MCP Apps 支持情况按客户端、版本、账户功能和实测记录区分。不要把模型名称或 `clientInfo` 当作权限或页面支持证据。
4. 兼容更新不扩大授权、不清除设置，也不重发业务写入。新范围仍需用户确认。网页备选使用普通登录，链接不携带访问凭据。
5. 旧 UI 资源保留原构建；服务器可返回兼容投影或安全网页查看入口。新会话可发现新版本，运行中的页面不强制切换。
6. 联网检查失败表示“更新情况未知”，不是“已是最新”。官方版本、本地锁定版本、实测版本和线上版本是四件不同的事。
