## 指引场景审阅

以下是对文档决策路径的审阅，不代表模型评测或客户端真测。

| 场景 | 指引要求 |
| --- | --- |
| 命令、写目录和 Node.js 均可用 | npm/npx，固定本次版本 |
| 无命令、无写入或缺 Node.js | 自动给 ZIP 链接和原生导入步骤，不要求开发环境 |
| 能执行命令但宿主目录不公开 | 原生 ZIP，不改私有目录或数据库 |
| 下载或导入需要人工操作 | 标为等待导入，不能把下载完成当作已安装 |
| 已有可用连接，更新 Skill | 复用连接与授权；本地自定义内容保留 |
| 只有新增入口、不支持替换 | 说明限制，不删除旧 Skill 或重复新增同名副本 |
| 无法核实版本或摘要 | 如实标记待核实，不能称为最新或已校验 |
| 连接、OAuth 或工具调用无法确认 | 分别标记状态，不查询业务项目代替验证 |
