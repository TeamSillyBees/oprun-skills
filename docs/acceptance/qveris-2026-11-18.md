# Qveris 接入验收（2026-11-18）

客户端：QVeris Studio 1.0.22，macOS。使用客户端可见界面与系统辅助功能；无 CDP 入口。未读取认证存储，未修改 OpRun 业务服务，未查询项目或执行业务写入。

## 已核实

- 原一句话安装入口失败：Qveris 的 web_fetch 明确返回“此地址未返回可读取的网页或文本：application/octet-stream”。首轮包含 17 次工具请求、4 次失败，随后人工停止；不是安装成功。
- Release 资产 MIME 元数据可设置为 text/plain，但实际下载仍可能被 GitHub 强制返回 application/octet-stream。因此入口必须使用 GitHub 网页版 INSTALL.md，包下载工具另走固定正式标签。
- 新会话默认只启用 QVeris MCP；已有 OpRun 连接未自动在会话中启用。启用后，客户端真实执行一次 oprun_account_context，工具轨迹显示已返回，回答显示调用成功。
- 原保存目录为 31 个工具。用户完成原生“保存并授权”的登录授权后，客户端显示“已验证连接，发现 43 个工具”，包括文件上传、工序执行及结算工具。
- 再次点击“验证并刷新”，客户端显示“连接验证成功，工具列表已更新”，保持 43/43 个工具。没有删除连接、扩大配置中的 Scope 或清空其他设置。
- 技能库搜索 oprun 无结果：MCP 已连接不等于 Skill 已安装。客户端提供“添加技能 → 上传 ZIP／上传技能文件夹”。
- v1.3.1 九项发布资产下载后与本地构建字节一致；33 项本地安装、更新、同步、打包、发布验证通过。
